# freedom closet

服を1着ずつ撮って手持ちの服を管理し、コーデと買い足しを提案するWebアプリ（スマホのブラウザ向け）。

## できること（初期版）
- **服の登録**：写真を選ぶだけで、AIが種類・色・柄（無地／ボーダー／チェック／花柄／ドット／柄もの）を判定してそのまま登録する（アルバムから何枚でもまとめてOK）。種類が分からなかった写真だけ1回タップで選ぶ。違っていたらあとから直す
- **確認したい服**：AIの判定に自信がない服には「確認」の目印が付き、クローゼットの上にまとめて出る。開いて保存すれば目印が消える
- **クローゼット**：登録した服を種類ごとに写真で見る・直す・削除。「確認したい」「しばらく着てない」「種類」で絞り込める。「この服でコーデ」でその服を使った案を見る
- **コーデ提案**：画面を開くとすぐ3案。体感の気温（寒い〜暑い）・目的・使いたい服はタップで変えるだけ。「ほかの案を見る」で別の3案。色合わせや袖・裾の扱いの説明つき
- **好き・好みじゃない**：評価は次の提案の順位に反映（好みじゃない組み合わせは出さない）
- **今日はこれ**：着るコーデを決めたら1タップで記録。昨日・一昨日に着た服は少し後回しにし、30日以上着ていない服はクローゼットで分かる
- **買い足し提案**：手持ちと合わせやすくコーデが増える服を、種類と色で提案。ユニクロ・GUの公式サイトの検索結果を開ける。画面を開くとすぐ提案する
- **AIの切り替え**：設定画面で「端末内AI」と「Claude API」を切り替え

写真と服の情報は端末内（IndexedDB）にだけ保存する。

### ホーム画面に追加して使う
iPhoneはSafariの共有ボタン →「ホーム画面に追加」。アプリのように開け、通信がなくても起動できる。
Safariはしばらく開かないサイトのデータを消すことがあるので、写真を残すためにもホーム画面からの利用がおすすめ。

## AIの切り替え
AIは `src/ai/types.ts` の `ClosetAI` という窓口に合わせて作ってあり、画面はこの窓口しか呼ばない。

| | 端末内AI（`local`） | Claude API（`claude`） |
| --- | --- | --- |
| 種類の判定 | Transformers.js＋CLIP（ゼロショット分類。1種類に複数の言い方を用意して合計） | Claudeが写真を見て判定（迷った候補も返す） |
| 色・柄の判定 | 写真から地の色と2色目を計算し、柄はCLIPで判定 | Claudeが地の色・2色目・柄を判定 |
| コーデ・買い足し | 独自の点数付け | Claudeが考える（写真は送らず、登録情報だけ送る） |
| 写真の送信 | しない | 判定時だけ、中継サーバー経由でAnthropicへ |

- 初期値は `.env` の `VITE_AI_PROVIDER`（`local` / `claude`）。アプリの設定画面でも切り替えられる
- Claudeモードで失敗したときは端末内AIで続ける（設定で切れる）
- 詳しくは [docs/ai-switching.md](docs/ai-switching.md)

## 動かし方
```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
```

Claude APIモードも試すとき（別のターミナルで）：
```bash
ANTHROPIC_API_KEY=sk-ant-... npm run dev:server   # http://localhost:8787
```
APIキーは中継サーバーだけが持つ。`VITE_` で始まる変数に入れるとブラウザに埋め込まれるので入れない。

## 開発
```bash
npm test          # 単体テスト（点数付け・色の判定・Claude用の通信部分）
npm run typecheck
npm run build
```

## 構成
```
src/
  domain/      服・コーデの型、色の扱い
  ai/          AIの窓口（types.ts）と切り替え（index.ts）
    local/     端末内AI（種類判定・色の抽出・コーデと買い足しの点数付け）
    claude/    Claude API版（中継サーバーを呼ぶ）
    schemas.ts アプリと中継サーバーのやりとりの形（zod）
  shop/        ユニクロ・GUの検索リンク、手選びの商品リスト
  storage/     端末内の保存
  screens/     画面
server/        Claude API の中継サーバー
docs/          設計メモ
```

## スマホで使う（GitHub Pages）
main に push すると `.github/workflows/pages.yml` が自動でビルドして GitHub Pages に公開する。URL は `https://<GitHubのユーザー名>.github.io/freedom-closet/`。
- はじめて使うときは、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にする（ワークフローが自動で有効にできなかったとき）
- 非公開リポジトリで Pages を使うには有料プランが必要。無料プランならリポジトリを公開にする
- 公開されるのはアプリの画面だけ。登録した服の写真や体型の数字は、開いた端末のブラウザの中にだけ保存される
- Claude API を使う中継サーバーは Pages には含まれない（端末内AIはそのまま使える）
