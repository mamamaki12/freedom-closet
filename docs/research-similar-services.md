# 似ているサービスの調査と、このアプリへの取り込み（2026-10-30）

国内外のクローゼット管理・コーデ提案アプリを調べ、「服の登録のしやすさ」「AIの判定」「コーデ提案」「使い続けるしくみ」の4つで比べた。
一次情報が取れないものは比較記事の記述によるので、細かい仕様は変わっている可能性がある。

## 各サービスの特徴

| サービス | 登録 | AIの判定 | コーデ提案 | 使い続けるしくみ |
| --- | --- | --- | --- | --- |
| XZ（国内） | 撮影せず「用意された服から近いものを選ぶ」方式。EC購入履歴からも登録 | （独自の判定は前面に出していない） | 「コーデ予報」：地域の天気・気温に合わせて手持ちから提案し、プッシュ通知 | コーデをカレンダーに記録して、かぶりを防ぐ。着こなしQ&AなどのSNS |
| JUSCLO（国内） | 1枚ずつ撮影。色・価格・季節・サイズなどを任意入力 | なし | なし（自分でカレンダーに組む） | 着用頻度ランキング、購入総額などの統計、「整理アイテム」タグ |
| WEAR by ZOZO | 購入履歴・コーデ投稿が中心 | ZOZOの「似合うラボ」系の診断、ChatGPT連携の提案 | 他人のコーデ写真が強み | 投稿・フォロー |
| Acloset | 写真→背景除去→種類・色を自動タグ付け。自撮りからアイテム検出も | 自動タグ付けあり。アップロードが不安定という声 | 天気と予定から毎日提案。「同じ服ばかり」「変な組み合わせ」の不満あり | コスパ（1回あたり価格）、着用頻度、SNS、フリマ。無料は100着まで＋広告 |
| Whering | 写真→背景除去→自動タグ付け、商品DBからも追加 | 自動タグ付けあり。誤りの直しが面倒という声 | 「Dress Me」（ランダム）とAI提案。AI提案は「好みと無関係」と言われがち | カレンダー、コスパ、荷造りリスト |
| Stylebook | 手で1着ずつ登録（2〜3時間かかる） | なし | なし（手で組む） | 統計が充実。iOSのみ、UIが古いという声 |
| Indyx | 背景除去、無制限無料。有料で人が代わりに登録 | 自動タグ付けは前面に出していない | AIではなく人のスタイリスト（有料） | コスパ、着用記録、スタイル診断 |
| Wardrowbe / Clueless / Alta（2026年の新興） | 写真のまとめ登録、レシートメールからの登録 | 種類・色・柄・雰囲気・きれいめ度まで自動タグ付け | 天気（気温・雨・風）、予定、着用履歴から毎日提案。重ね着にも対応 | 着用履歴、繰り返しの検知 |

## 共通して言われていること
1. **やめる一番の理由は、最初の登録の手間。** 自動タグ付けと背景除去は今や標準。「まず20着だけ」と勧める記事が多い
2. **AIのタグ付けの誤りを直すのが面倒。** 誤りがどこにあるか分からないと、全部見直すことになる
3. **AIコーデ提案は「ランダム」「同じ服ばかり」と言われやすい。** 天気・予定・着用履歴・好みの反映が差になる
4. **着た記録（カレンダー・着用頻度）は、XZ・JUSCLO・Whering・Indyx・新興勢に共通。** かぶりを防ぎ、着ていない服に気づける
5. 新興勢は**柄・雰囲気まで**タグ付けし、天気は気温だけでなく雨・風も見る

## このアプリへの取り込み（今回のPR）
| 課題 | 取り込み |
| --- | --- |
| 柄ものを「黒のシャツ」と呼んでしまう（実写真で確認した弱点） | 服に**柄（無地／ボーダー／チェック／花柄／ドット／柄もの）と2色目**を持たせた。端末内AIはCLIPで柄も判定し、画素から2色目を取る。Claudeにも柄・2色目・迷った候補・確からしさの基準を聞く。コーデの点数は「柄は1点まで」「柄の色とほかの服の色をそろえる」を見る |
| 端末内AIの種類判定の精度 | 1種類に言い方を複数用意して点数を合計（プロンプトのアンサンブル）。ポロシャツ・ブルゾン・カーゴパンツ・スウェットパンツを追加 |
| AIの誤りをどこから直せばいいか分からない | 確からしさが低い服に**「確認」の目印**を付け、クローゼットの上に「自信がない服がN着」と出す。開いて保存すれば目印が消える（本人が選んだ服には付けない） |
| 同じ服ばかり提案される | コーデに**「今日はこれ」**ボタン。昨日・一昨日に着た服は少し後回しにする（端末内AI・Claudeとも） |
| 着ていない服に気づけない | クローゼットに**「しばらく着てない」**の絞り込み（30日以上）と、最後に着た日を表示 |
| 服が増えると一覧が長い | クローゼットに種類の絞り込みチップ |

## 次に検討すること（今回は見送り）
- 背景除去（端末内で動く軽いセグメンテーションモデルの検証が必要。写真の見た目がそろい、色の判定も安定する）
- 天気の自動取得（PR #4 で別途）と、雨・風の反映
- 「着た記録」のカレンダー表示、コスパ（価格入力は手間なので慎重に）
- 柄の種類をさらに細かく（ストライプとボーダーの区別など）は、実写真での精度を見てから
